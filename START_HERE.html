The updated source includes two new Lab simulations, real PCB photography, a blue water-meter spotlight, and a project editor backed by Supabase.

  1. Read README.md for the complete setup and migration procedure.
  2. To preview locally, open a terminal in this folder and run:
    npm ci
npm run build
python3 -m http.server 8000 --directory site
    Then open localhost:8000. Do not open the site by double-clicking index.html; it uses JavaScript modules.
  3. Create your Supabase project, run the two SQL files in order, create an admin account and grant it access.
  4. Import the code into Vercel. Use Other, build npm run build, output site, and add both Supabase public environment variables.
  5. Visit the Project studio link after deployment. Your Netlify site stays unchanged until you migrate it.

Without Supabase configuration, the website previews with its five original projects; the editor displays setup instructions.
