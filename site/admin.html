One-time setup required

Connect Supabase using the README included with your website. Add SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY to Vercel, then redeploy.

There is no default admin password. You create your own account and grant it editor access during setup.

Need a password reset? Your Supabase project owner can send a recovery email or update your account from the dashboard.
